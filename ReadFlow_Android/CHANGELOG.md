# ReadFlow Android 更新日志 (CHANGELOG)

本文件记录 **ReadFlow（四六级外刊精读系统 · Android 移动版）** 的版本迭代历史。
移动端为独立版本线（v1.x，git 标签 `android-v1.x`），与桌面端 v2.x 线互不重叠；v1.0 的功能基线对齐桌面 **V2.1**。

## [v1.1] - 2026-11-02 · 六项体验提升

* **计时防锁屏**：限时器运行期间自动保持屏幕常亮（原生 KeepAwake），暂停/到时/重置即恢复休眠，阅读计时不再被锁屏打断。
* **深色跟随系统**：主题组新增「🌗 跟随系统」档，系统深浅色切换时应用实时跟随，选择持久化记忆。
* **快捷标注流**：查词台标题下方新增常驻快捷标注条（🔴生词 / 🟡核心 / 🟢已熟 / ✕清除），一词一点直达，无需滚动到下方大按钮。
* **划词翻译气泡**：在正文中选中 ≥2 个英文词，选区上方浮出「🌐 翻译选中」气泡，点按直达词句翻译台并自动填充解析——解决触屏划词后还要手动切换 Tab 的麻烦。
* **抓取源健康度**：获取页新增「源状态」条，六个 RSS 源逐个显示 ✓成功 / ✗失败（含失败原因：超时 / 陈旧 / 正文过短），点失败源即可单独重试，不再只知道笼统的 OFFLINE。
* **每日学习提醒**：首页新增「🔔 每日提醒」开关与时间设置，到点本地通知催你打卡（Android 13+ 自动请求通知权限），连击不靠自觉。

## [v1.0] - 2026-11-02 · Android 版首发

* **移动优先整体重构**：以桌面 V2.1 功能集为基准（纯逻辑模块逐行复用），UI 按手机习惯全新设计，非桌面布局套壳。
* **全局框架**：底部 6 键标签栏（首页/精读/获取/文章库/单词库/统计，角标实时同步）+ 精简头部（品牌/版本徽章/主题组/上手指南）。
* **精读页**：单栏正文 + 文章目录侧滑抽屉（难度/题型筛选 + 底部统计条）+ 查词台底部弹层（三 Tab：查词详情/词句翻译/本文生词，点词自动弹出，非模态可连续查词）+ 单行横滑工具栏 + 段落朗读/译文常显按钮 + 专注阅读模式。
* **逐词精读引擎**：134 词元级分词点查、牛津离线词典 0ms 秒查、三色行内标注（快捷键保留）、派生词/同义词、个人批注行内显示、长难句拆解、四六级仿真自测（会话计数 + 未答圆点）。
* **文章获取**：客户端真 RSS 爬虫（CapacitorHttp 原生网络栈 + fast-xml-parser + Readability 正文提取），逐行复刻桌面 news.py 的 12 秒总时限 / 60 天时效门控 / 段落切分 / 词数分级（>330 词=CET-6）/ Wikipedia 兜底，三态诚实反馈（READY/CRAWLING/OFFLINE）+ 防连点。
* **朗读**：有道词典真人音频逐句队列（预取 + 3 秒起播看门狗），离线自动降级系统语音引擎（原生 TTS 桥，无需手势逐段授权）。
* **文章库/单词库**：搜索 + 阅读状态 + 三联筛选（难度/题型/来源）、JSON 备份导出、四态生词筛选、闪卡遮盖自测、CSV 导出（BOM 保留）——导出统一走系统分享面板。
* **时间统计**：6 大 KPI、364 天 GitHub 式热力图（三种模式横滚）、14 天趋势、五题型覆盖度、打卡记录与跨实体清零守卫。
* **全局**：三主题持久化、8 项偏好设置持久化、安徽专升本全链路、安卓返回键逐级导航（弹窗→查词台→抽屉→首页→退出）、数据存于应用私有空间（卸载才清除）。
